# Illustration Prompt

## 1. Breadboard Anatomy

```md
Use case: scientific-educational
Asset type: supporting blog infographic
Primary request: Create a clear educational infographic showing the anatomy of a solderless breadboard for beginners.
Scene/backdrop: warm cream background with a large breadboard diagram.
Subject: stylized breadboard with callouts pointing to terminal strip, power rail, center gap, rows, columns, and jumper wire.
Style/medium: flat technical illustration, soft-brutalism, clean educational callout diagram, friendly Runutin visual tone.
Composition/framing: breadboard centered, callout lines around it, enough spacing for readable labels.
Color palette: cream, teal, yellow, coral, mint, black outlines.
Text: short callout labels only: "Terminal Strip", "Power Rail", "Center Gap", "Row", "Column", "Jumper Wire".
Constraints: infographic must teach breadboard parts, no people, no logos, no watermark.
Avoid: decorative-only image, messy wiring, unreadable tiny text, photorealism.
```
