# Illustration Prompt

## 1. Arduino Ecosystem Map

```md
Use case: infographic-diagram
Asset type: supporting blog infographic
Primary request: Create an educational infographic that explains the Arduino ecosystem as connected parts: board, microcontroller, Arduino IDE, sketch, libraries, shields, sensors, modules, and prototype.
Scene/backdrop: warm cream background with clean infographic blocks connected by arrows.
Subject: a central Arduino-like board surrounded by labeled conceptual icons for IDE, code sketch, library, shield, sensor, actuator, and final prototype.
Style/medium: flat illustration, soft-brutalism, clear diagram style, thick black outlines, friendly Runutin visual tone.
Composition/framing: landscape-friendly centered map, readable spacing, simple arrows showing relationships.
Color palette: cream, teal, yellow, coral, mint, black outlines.
Text: use short English labels only if needed: "Board", "IDE", "Sketch", "Library", "Sensor", "Shield", "Prototype".
Constraints: infographic must teach the relationship between Arduino parts, no people, no logos, no watermark.
Avoid: decorative-only scene, dense paragraphs, fake code blocks, photorealism.
```

